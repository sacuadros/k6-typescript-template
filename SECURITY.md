# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/sacuadros/k6-typescript-template/security/advisories/new) with enough information to reproduce and assess the issue without including secrets or unrelated personal data.

## Supported versions

Security fixes apply to the latest commit on the default branch. This repository is a starter template, not a hosted service.

## Load-testing safety

Only target systems you own or have explicit permission to test. Never commit credentials, private endpoints, or sensitive test data.
