# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm ci`.
3. Make the smallest change that solves the problem.
4. Run `npm run check`.
5. Open a pull request describing the behavior changed and the verification performed.

Do not include secrets, production URLs, or load-test results containing sensitive data. New examples must be safe by default and must not generate meaningful load without an explicit command.
